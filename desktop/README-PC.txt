DevAI Studio 3.2.0 — PC-версия для Windows
============================================

Установка
1. Запустите DevAI-Studio-Setup-3.2.0.exe.
2. Выберите Windows 7, Windows 10 или Windows 11.
3. На странице «Компоненты» нажмите «Полная версия» или оставьте все галочки.
4. Установите программу и запустите с ярлыка на рабочем столе.

Компоненты установщика
- DevAI Studio и Java Runtime 8 — обязательные файлы.
- Vexel APK — конструктор Vexel для телефона или эмулятора.
- ADB — установка Vexel в эмулятор без Android SDK.
- Ярлыки DevAI Studio и Vexel.

Языки кода
В чате и в «Настройках» выберите основной язык: Kotlin, Java, Python,
JavaScript, TypeScript, Dart, Swift, C, C++, C#, Go, PHP, Ruby, SQL, Bash
и ещё десятки языков. Примеры, тесты и команды будут на выбранном языке.

Первый запуск
1. Откройте вкладку «Настройки».
2. Выберите провайдера: OpenAI, Gemini, Claude или свой OpenAI-совместимый API.
3. Введите Base URL, модель и API-ключ.
4. Нажмите «Проверить», затем «Сохранить».

Vexel
Vexel — Android-конструктор, который входит в DevAI Studio без изменений.
APK лежит рядом с программой: DevAI-Android.apk.
ADB уже входит в полную версию, отдельный Android SDK не нужен.

Как запустить Vexel в PC-версии:
1. Установите Android-эмулятор (BlueStacks, LDPlayer, Android Studio Emulator)
   или подключите телефон с включённой отладкой по USB.
2. Запустите эмулятор и нажмите ярлык «Vexel» на рабочем столе или в меню «Пуск».
3. Скрипт установит APK и откроет Vexel. Если прямой запуск недоступен,
   откроется DevAI Studio — выберите Vexel в приложении.
4. То же можно сделать на вкладке «Vexel»: кнопки «Установить Vexel»,
   «Открыть Vexel» и «Проверить ADB».

Данные
Настройки: %APPDATA%\DevAI Studio\settings.properties
История чата: %APPDATA%\DevAI Studio\history.txt

JRE
В установщик входит Java Runtime Environment 8 (x64), поэтому отдельная
установка Java не нужна.
